Nikhil X Check V2A

Nikhil X Check V2A is a private personal application used by Nikhil Segel to collect and analyse information from his own X account.

The application uses Google Drive to store and retrieve application-generated data files used by the service.

Access to Google Drive is limited to files specifically used with this application. The application does not request general access to the user's Google Drive.

The service is not offered to the public and does not sell, distribute, or commercially exploit user data.
