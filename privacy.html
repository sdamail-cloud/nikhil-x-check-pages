Privacy Policy — Nikhil X Check V2A

Last updated: September 2026

Nikhil X Check V2A is a private personal application operated by Nikhil Segel.

Information accessed

The application may access Google Drive files that the user has specifically authorised for use with the application.

The application uses the Google Drive drive.file permission. This permission allows access only to files created by or specifically used with the application rather than providing general access to all files in the user's Google Drive.

How information is used

Google Drive access is used solely to:

  • read application data used by Nikhil X Check;
  • update application-generated data files;
  • maintain the operation of the service.

Google user data is not used for advertising, profiling, resale, or marketing.

Sharing of information

Google user data accessed by Nikhil X Check V2A is not sold or shared with third parties for advertising or marketing purposes.

Data may be processed by infrastructure providers required to operate the application, including Google Cloud services.

Data storage and security

Authentication credentials and application secrets are stored using secure cloud secret-management services and are not intentionally exposed in application logs.

Access is restricted to the minimum permissions required for the application to operate.

Data retention and deletion

Application-generated files remain under the control of the Google account owner. The account owner may revoke application access or delete relevant files at any time.

Google API Services

Nikhil X Check V2A's use of information received from Google APIs will comply with the Google API Services User Data Policy, including applicable Limited Use requirements.
